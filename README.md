# ⚓ BOOK HARBOUR

> Every book deserves a safe harbour.
> （すべての本に、帰る港を。）

BOOK HARBOUR は、本を一隻のヨットに見立て、
読書を「航海」として楽しみ、記録するためのWebアプリです。

私は長年ヨットを楽しんできました。

ヨットハーバーには、
出航を待つ艇、
航海から帰ってきた艇、
整備中の艇が静かに並んでいます。

私にとって本も同じ存在です。

まだ読んでいない本。
今まさに読んでいる本。
人生に影響を与え、読み終えた本。

それらは私の人生という海を共に旅するヨットです。

BOOK HARBOUR は、
そんな本たちが集う港をイメージして作っています。

---

# プロジェクトの目的

このプロジェクトには二つの目的があります。

## ① 自分が本当に使いたい読書アプリを作ること

本棚管理ではなく、

「読書体験を豊かにする港」

を目指します。

## ② AI駆動開発を体験すること

会社でAI駆動開発の流れが進む中、

ChatGPTと対話しながら

・設計する

・試作品を作る

・改善する

という開発スタイルを学ぶことも、このプロジェクトの目的です。

このプロジェクトは、

「完成させること」

「AIと一緒に育てること」
