# ⚓ BOOK HARBOUR

> Every book deserves a safe harbour.
> （すべての本に、帰る港を。）

## 概要

BOOK HARBOUR は、本を一隻のヨットに見立て、
読書を「航海」として楽しみ、記録するWebアプリです。

このプロジェクトには二つの目的があります。

1. 自分が本当に使いたい読書アプリを作ること
2. AI駆動開発を学ぶこと

完成を急ぐのではなく、

設計
↓

試作品
↓

体験
↓

改善

というサイクルで育てていきます。
